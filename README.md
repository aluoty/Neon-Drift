# Neon-Drift

A 2D neon-themed racing game built with **React**, **TypeScript**, and **HTML5 Canvas**.

## Tech Stack
- **React 19** — UI components (menu, HUD, minimap)
- **TypeScript** — Full type safety across engine and components
- **Vite** — Fast build tool
- **HTML5 Canvas** — Game rendering (road, cars, particles, stars)

## Getting Started

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
npm run preview
```

## Features
- Single Player, AI Race, and local Multiplayer modes
- 3 tracks with unique road curves and visuals
- 4 selectable cars with different stats
- Nitro boost with particle effects
- Procedural engine audio (Web Audio API)
- Clickable minimap (expandable to full-screen circular view)
- Scrolling starfield background
- Off-road speed penalty
- Level progression system
